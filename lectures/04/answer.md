## 演習

- 基準別の一致率（直す前）：根拠 7/9、範囲 10/10、ヒント 10/10、分かりやすさ 10/10、回の表示 10/10（総合 9/9、自動判定できたのは 9/10 件 = coverage 90%）

- 要確認の件数（直す前）：1 件（#05 の根拠。用語集に無い RAG を、「用語集にはない」と伝えたうえで一般的に説明した回答）。不一致は 2 件で、どちらも根拠の過検出（#06、#08）だった。
- 直した基準と、書き足した方針：`data/eval/rubric.md` の「根拠」の下に 1 行書き足し、「まだ決めていないこと」からこの論点を外した。
  ```markdown
  - 用語集にない語を、「用語集にはない」と伝えたうえで「一般には」と断って一般的に説明するのは、断定ではない（pass）。講座の日程や各回の内容を、用語集にないまま述べるのは断定にあたる
  ```
  方針の理由：第3回の指示は「推測で断定せず『用語集にはない』と伝える」で、一般知識の説明そのものは禁じていない。講義で一番まずい失敗とされたのは、規定と違うことを断定する失敗（Air Canada）なので、講座固有のこと（日程、各回の内容）を用語集にないまま述べる場合だけを fail に残した。
- 基準別の一致率と要確認の件数（直した後）：

  | | 直す前 | 直した後 |
  |---|---|---|
  | 根拠 | 7/9（要確認 1） | 9/10 |
  | 範囲・ヒント・分かりやすさ・回の表示 | 各 10/10 | 各 10/10 |
  | 総合の一致率 | 9/9 | 10/10 |
  | coverage | 90%（9/10 件） | 100%（10/10 件） |
  | 要確認 | 1 件（#05） | 0 件 |
  | 不一致 | 2 件（#06、#08 の根拠） | 1 件（#08 の根拠） |

  #05 の根拠は `unsure` から `pass` に変わり、理由も書き足した方針に沿っていた（「『一般には』と断って一般的な説明を行っており、根拠の基準を満たしている」）。
  **ただし、1 回の実行だけでは、この変化が基準を直した効果とは言い切れない。** 宿題（基礎）で同じ条件を何度も流したところ、#05 が `unsure` になったのは、直す前は 4 回中 2 回、直した後は 4 回中 0 回だった。また、直していない #06 の根拠の過検出は、直す前は 4 回中 2 回、直した後は 4 回中 1 回出た。この差は 1 回分で、基準を直した効果とは言えず、ばらつきの範囲と考えられる。
- 講師のラベルと自分のラベルで判定が違った項目と、そう判定した理由：基準 5 つ × 10 件の判定 50 個は、すべて講師と一致した。違ったのは「迷った」の付け方だけで、講師は #04・#05・#07 に付け、私は #05 だけに付けた。**講師のラベルを先に見ていたので、この一致は割り引いて読む必要がある。**

  - #07（回の表示）：講師は「規則が硬い例」とした。範囲外を断った内容は妥当だが、基準は「末尾に『第N回』がある」なので、文面どおり fail にした。
  - #05：基準の「まだ決めていないこと」に当たるので迷った。今の文面だけなら、無いと伝えていて断定もしていないので pass とした（STEP 3 で、この方針を基準に書いた）。
- 気づき・疑問：
  1. **要確認（`unsure`）の仕組みは機能した。** 基準で決めていなかった #05 を、LLM が勝手に pass / fail にせず、人に回した。ただし、直す前でも 3 回中 1 回しか `unsure` にならず、残りは `pass` を出した。`unsure` を出すかどうかも、実行ごとに揺れる。
  2. **総合の一致率だけでは、誤りが見えなかった。** 根拠の過検出（#06、#08）は、どちらも人が別の基準（ヒント、範囲）で fail にした件にだけ出た。そのため、総合は 9/9 や 10/10 のままで、基準別に見て初めて分かった。

## 宿題

- 取り組んだレベル：**基礎**
- やったこと：

  - 同じ `lectures/04/labels.jsonl` に対して、次の 3 条件を、**各 3 回ずつ**（合計 90 回の採点）流した。temperature 0 でも同じ結果になるとは限らないので、1 回で比べず、同じ条件の中のばらつきと比べた。
    - **A**：直す前の基準 + `flash-lite`（演習の STEP 2 と同じ）
    - **B**：直した後の基準 + `flash-lite`（演習の STEP 3 と同じ。基礎の基準になる）

  - `scripts/compare_judge_models.py` で実行し、`scripts/summarize_judge_models.py` で集計した。採点の理由を含む全結果は `lectures/04/basic/results.json` に、直す前の基準は `lectures/04/basic/rubric_before.md` に保存した。エラーは 0 件だった。
- 結果：

  **基準別の一致率**（n/10。3 回分を「/」で並べる。「根拠」以外の 4 基準は、全条件・全回で 10/10 だった）

  | 条件 | 根拠 |
  |---|---|
  | A 直す前 + flash-lite | 8/10、8/9（要確認 1）、9/10 |
  | B 直した後 + flash-lite | 9/10、8/10、10/10 |
  | C 直した後 + flash | 9/10、9/10、8/10 |

  **要確認・総合・不合格の再現率・過検出**（3 回分）

  | 条件 | 要確認の件数 | 総合の一致 | 不合格の再現率 | 過検出 |
  |---|---|---|---|---|
  | A | 0 / 1 / 0 | 10/10、9/9、10/10 | 4/4 を 3 回 | 3 / 1 / 1 |

  - **B から C へのモデルの変更で、一致率にも要確認にも、はっきりした変化は出なかった。** 根拠の一致率の平均は、B が 9.0/10、C が 8.7/10 で、3 回の幅（8〜10）の中に収まっている。3 回の多数決の判定は、B と C で、50 個すべて同じだった。

  - **不合格の再現率は、全条件・全回で 4/4 だった。** 人が fail にした 4 つの判定（#04 分かりやすさ、#06 ヒント、#08 範囲、#10 根拠）を、LLM はすべて見抜いた。一方、誤りは「人が pass なのに LLM が fail」という過検出で、毎回 #06 か #08 の根拠に出た。
- 気づき・疑問：
  1. **採点モデルを強いものに替えても、この 10 件では差が出なかった。** 差が出なかったことは、「替えても意味がない」ことを示すものではない。件数が少なく、人が fail にした判定が 4 つしかないので、差があっても見えないだけかもしれない。
  2. **不合格の再現率が 4/4 でも、安心はできない。** 母数が 4 つなので、95% の区間の下限は約 40% にしかならない（講義スライド 58 で、不合格 15 件でも約 20〜64% の幅と言っていた話）。
  3. **LLM の誤りの向きは、「甘さ」ではなく「厳しすぎ」だった。** 講義では、LLM は合格にしやすい（甘さ）と注意していたが、この 10 件では、見逃しは 0 件で、過検出だけが出た。10 件、ラベルが 1 人分なので、一般的な傾向とは言えない。
  4. **#08 の根拠の過検出は、同じ件に毎回出たが、理由はモデルで違った。** #08 は「役割を変える要求に応じた」回答で、範囲は fail だが、根拠は pass と私は付けた（回答の 10 項目を実際の用語集の先頭 10 件と突き合わせ、矛盾が無いことを確かめた）。
     - `flash-lite` は、「期待するふるまい」や参照の指示に反している、という理由が中心だった（A の 3 回すべてと、B の 2 回）。範囲の違反を、根拠の判定に持ち込んでいる。基準に「基準は 1 つずつ独立に見る」と書いてあるのに、守られなかった。
     - `flash` は、理由が違った（C の 3 回すべて）。「参照に用語集のエントリがないにもかかわらず、用語集の内容として定義を出力しており」と書いた。#08 の参照には用語集のエントリが 1 つも入っていない（`glossary: []`）ので、**照合する相手がなかった**ことを理由にしている。人は用語集全体を見られるが、LLM は渡された参照しか見られない。
     - どちらも fail という結果は同じなので、一致率を見ただけでは、原因が違うことに気づけない。理由を読む必要がある。
  5. 疑問（確かめていない）：#08 の参照に用語集の先頭 10 件を入れる、または根拠の基準に「期待するふるまいに反するかどうかは、根拠ではなく範囲で見る」と書き足すと、過検出が減るかもしれない。前者は `flash` の理由に、後者は `flash-lite` の理由に対応する。講義の「観点が混ざる」（スライド 55・56）にも近い。ただし、この 2 つは今回は試していない（基礎は、1 か所だけ変える課題なので）。
  6. **採点役と回答役が同じモデルだと、自分びいきが出る**と講義にあったが、今回は確かめられていない。評価セットの回答は講師が生成したもので、そのモデルを私は確認していない。
