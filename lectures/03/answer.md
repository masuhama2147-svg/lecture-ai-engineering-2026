## 演習

- 第1回（素のLLM）とエージェントの回答の違い：
  「宿題の3レベル」を聞くと、第1回の `app.ask` は、用語集を見られないので一般論の「難易度別の3段階」を答えた（第1回の実験では、講座固有の質問に 0/7 で正解できなかった）。エージェントは `search_glossary` で用語集を引いてから答え、「基礎＝講義内容の確認／実装＝自分でコードを書く／発展＝調査や試行、どれか1つで完了、原則採点しない」という**正しい内容**を、最後に「第1回」と添えて返した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：
  - 「3レベル」の質問：`search_glossary({'query': '3レベル'})` の1回。
  - 「LoRAとQLoRAの違いは？」：`search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` の2回。用語が2つあっても、`query` に1つずつ入れて別々に呼んでいた。docstring の「query には調べたい用語を1つだけ入れる」に従っている。
  - 「第2回の内容から確認問題を1問出して」：`make_quiz({'lecture': 2})` の1回。
- 1つの質問での LLM 呼び出し回数（`requests`）：上の3つとも **2回**（1回目でツールを呼ぶと決め、ツールの結果を受けた2回目で回答する）。ツール呼び出しは1回目の中で並列に行われるので、LoRA と QLoRA の2つを検索しても `requests` は 2 のまま。
- 追加したツールと、docstring に書いた説明：
  `make_quiz(lecture: int) -> str`。docstring は「指定した回（1始まりの整数）の用語から、確認問題を1問作って返す。『第2回の確認問題を出して』『クイズを出して』のように、利用者が学習内容を確かめる問題を求めたときに使う。返り値の question を利用者に出題する。answer は利用者が答えたあとの解説に使い、出題と同時には見せない。」
  用語集から指定の回の用語を `random.choice` で1つ選び、`{"question": "「○○」の意味は？", "answer": 定義}` を返す。用語が無い回（`lecture=0` など）は、エラーにせず「用語がある回: 1, 2, 3, 5」と返す。実際に呼ぶと、答えは伏せたまま問題だけが出題された。`uv run pytest -q` も通る。

- 気づき・疑問：
  1. **エージェントは、素のLLMが外す質問に答えられた**。ただし、答えの正しさは「用語集に書いてあるか」で決まる。用語集に無い質問（最終課題の配点）は、検索しても見つからず、全条件で「用語集には載っていない」と伝えた（C だけ 1 回は伝えなかった）。推測で断定しない指示が効いている。
  2. **指示を1行消しても、動作は変わるとは限らない**。「必ず検索する」という同じ趣旨が、ツールの docstring にもあった。両方を消しても検索は続いた。ツールの説明文の1行目や、別の指示（「用語集に見つからないことは…」）などの手がかりが効いていると考えられるが、**どれが効いているかは確かめていない**。ふるまいを変えたいときは、変更が本当に効いたかを、実際に動かして確かめる必要がある。
  3. **指示を足すと副作用が出る**（C）。確認問題の指示は LLM 呼び出しを増やし、「回を示す」を押しのけ、1回は質問への回答そのものを飛ばした。
  4. **ツールの引数はモデルが決める**。`make_quiz` の `lecture` に、質問と関係のない回（1）を渡した回があった。docstring に「回の番号」としか書かなかったので、どの回を渡すかの手がかりが足りなかったのかもしれない。
  5. **承認つきツール**：承認待ちを結果として受け取るため、`output_type` に `DeferredToolRequests` を加える（課題文の指示どおりに加えた。加えない場合は試していない）。また、承認の前後の2回の実行を、使用量を引き継いでつなげないと、`[usage]` の `requests` が実際より小さく出た（承認後の分しか数えない）。直して、テストに加えた。
  6. **ADK と Pydantic AI は、同じ指示・ツールで同じふるまいをした**。違いは書き方と、入力トークンが毎回 約125 多い点。この差の原因（ADK が足す指示文か、ツール定義の渡し方か）は確かめていない。
  7. **限界**：各条件3回、モデルは1つ、質問は3つ。回答の機械判定（語句の一致）は簡易で、回答の原文を読んで確かめた。判定の取りこぼしが2つあり（「登録されていません」「掲載されていません」を「用語集にない」と数えていなかった）、語を足して再採点した。ADK 版の数字は Pydantic AI 版とは別の時刻に測っている。
- AIツールの利用：実装・実行・集計は Claude Code に依頼して実行した。回答の中身は、保存した記録（`lectures/03/basic/results.json`、`lectures/03/advanced/adk_results.json`）と、実際に動かした出力で確かめた。
- 提出物の場所：基礎は `lectures/03/basic/`、発展は `lectures/03/advanced/` と `adk_agent/`、スクリプトは `scripts/compare_agent_variants.py` と `scripts/compare_adk.py`。
